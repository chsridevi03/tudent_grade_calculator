# Student Grade Calculator 🐍

## About the Project
The Student Grade Calculator is a beginner-friendly Python project that calculates students' total marks, percentage, grades, and pass/fail status.

## Features
- Student name input
- Marks entry for five subjects
- Total marks calculation
- Percentage calculation
- Automatic grade assignment
- Pass/Fail status

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Run:

```bash
python student_grade_calculator.py
```

## Learning Outcomes
- Python variables
- User input
- Conditional statements
- For loops
- Arithmetic operations
